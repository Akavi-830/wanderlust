# Wanderlust
[visit wanderlust]{https://wanderlust-ohaa.onrender.com/listings}

Airbnb-inspired full-stack accommodation booking platform.

## Features

- User Authentication
- Property Listings
- Image Uploads (Cloudinary)
- Wishlist System
- Booking System
- Reviews & Ratings
- Interactive Maps (Leaflet)
- Search & Category Filters

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- Passport.js
- EJS
- Bootstrap
- Cloudinary
- Leaflet

## Installation

npm install

Create .env file

npm start
